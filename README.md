## 画面优先

直接观察一张公孙离真实游戏截图，点图标记关注位置、选择行动并写下理由；提交后才开放参考观察区。作答前没有虚构剧情或预先解释局面的卡片。不提供战术正确率或胜率提升承诺。

默认截图来自九游2023年公开教程，来源详见 assets/real-scenes/SOURCE.md，保留原画面及水印。旧教程不代表当前版本攻略。可以换成自己的JPG/PNG/WebP截图，在浏览器中保存和恢复；自己的图片不会上传GitHub或发送给模型。

## 保存与核对

首次判断、复盘补充和实战反馈分开保存。文字记录可导出，自己的截图不包含在JSON中；请自行保留原文件。页面不调用实时AI、不自动分析录像，最多保留最近30次文字练习记录。

旧训练与对局复盘使用独立记录，清除画面练习不会清除它们。46项本地检查通过，并完成桌面/手机、图片恢复、延迟导入、清理失败和零上传检查；这些检查不证明游戏水平提升。
