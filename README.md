## 当前功能

从公孙离前期对线的具体片段出发，确认事实、保存一项训练或观察任务，并记录实际反馈。

情境练习包括 2 个先试、4 个边练、2 个新情境，支持草稿、首次答案、重复练习、实战任务和导出。目前全部是未经玩家审核的原创文本演示，非真实回放，不显示正式分数或能力等级，不代表训练效果。真实回放训练需等待有公开许可的材料和人工审核。

## 数据与运行

这是静态网页，不调用实时 AI，不自动分析录像。记录只保存在玩家当前浏览器，复盘和训练使用独立存储，分别最多保留 30 次；玩家主动导出后可自行选择是否分享。作者不会自动收到自述或反馈。

仓库不包含玩家记录、密钥、私人配置或服务端。38 项本地检查通过，并完成桌面、手机训练及原复盘流程检查；这些检查不能证明实战提升。
